# Member photos

Each member card shows `assets/team/<slug>.png`. The files here are initial
placeholders in the SPARK palette — to use a real photo, replace the file
keeping the same name and the `.png` extension. Square images work best
(they are cropped to a circle); around 400×400 is plenty.

    ziqi-wang.png
    mengsha-kou.png
    jian-tang.png
    mengying-zhang.png
    liuyue-yin.png

To add a member, drop in `<slug>.png` and copy an existing `<li class="member">`
block in `spark.html`.
